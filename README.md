# Alex Personalized Agent Skills

##  Stem_Explainer_Meta_Skill: 
A meta-skill for AI agent to explain complicated Science concepts thoroughly, covering all relevant concepts of that topic.

##  kaggle-playground-contest:
A skill for participating in Kaggle monthly playground contests. Runs an iterative verify->submit->log->compare loop, tracking progress in DOCUMENT.md (append-only experiment log) and BEST_APPROACH.md (checkpoint), with local cross-validation gating before any submission.
